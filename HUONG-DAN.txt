GOI VA V6 - VUONG CHI

MUC TIEU
1. Giu phong cach font condensed dang dung local.
2. Tranh Cloudflare bi roi ve Segoe UI/Arial rong lam tieu de xuong dong.
3. Sua trang CONG TRINH khong con phu thuoc URL du-an.html.
4. Doi ten asset sang V6 de tranh trinh duyet/CDN bam cache file V5 cu.

CACH DUNG
1. Giai nen TOAN BO noi dung goi nay vao:
   F:\webnhap\vuong-chi-v5

   Khi dung, ban se thay:
   F:\webnhap\vuong-chi-v5\index.html
   F:\webnhap\vuong-chi-v5\APPLY-FIX-V6.bat
   F:\webnhap\vuong-chi-v5\assets\styles-v6.css
   F:\webnhap\vuong-chi-v5\assets\app-v6.js

2. Double-click APPLY-FIX-V6.bat.
   Script chi doi cac tham chieu trong file .html:
   styles-v5.css -> styles-v6.css
   app-v5.js     -> app-v6.js

3. Mo index.html local va du-an.html local de kiem tra.

4. Push len GitHub:
   cd /d F:\webnhap\vuong-chi-v5
   git add .
   git commit -m "Fix font and Cloudflare project route v6"
   git push

FONT
- Tren Windows, CSS van uu tien Bahnschrift/Bahnschrift Condensed de giu dung cam giac local.
- Neu browser/OS khong cho dung font local, website tu dung Barlow Condensed tu Google Fonts de giu dang chu hep, dam va cong nghiep.
- Goi nay KHONG chua file font Microsoft.
